# 🎓 ExamPortal – Online Examination System

**ExamPortal** is a responsive web-based Online Examination System developed using HTML, CSS, JavaScript, and Bootstrap 5. It allows students to register, log in, attend online exams, view their results, and review correct answers.

## 🚀 Features

- 🔐 **Student Authentication** – Register, log in, and log out.
- 📝 **Online Exams** – Attempt HTML, CSS, and JavaScript quizzes.
- ⏱️ **Exam Timer** – Automatic submission when time runs out.
- 📋 **Question Palette** – Navigate between questions easily.
- ⭐ **Mark for Review** – Mark questions for later review.
- 📊 **Instant Results** – View scores, percentages, and pass/fail status.
- ✅ **Answer Review** – Check correct answers and your selected answers.
- 📈 **Dashboard** – Track completed exams and average scores.
- 📚 **Results History** – View previously completed exams.
- 👤 **Student Profile** – View personal and course information.
- 📱 **Responsive Design** – Works across desktop, tablet, and mobile screens.
- 💾 **Local Storage** – Stores student accounts and exam results in the browser.

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure `index.html`, `index.css`, and `index.js` are in the same folder.
4. Open `index.html` in your browser, or use the VS Code Live Server extension.
5. Register a new account or use the demo credentials below.

## ⚠️ Limitations

- This project is a frontend demonstration and does not use a backend database.
- User accounts and results are stored in browser Local Storage.
- Authentication is not secure enough for a production application.
- Data may not be available in another browser or on another device.
- Exam questions are predefined in JavaScript.
